# v0.32.alpha Release Notes

## Highlights

### DeepStream SDK 8.0 Support
DSL now supports NVIDIA DeepStream SDK 8.0 in addition to existing support for versions 6.4, 7.0, and 7.1.

**Key DeepStream 8.0 Features:**
- **Platform Support**: Ubuntu 24.04 LTS and NVIDIA Blackwell GPU architecture
- **Jetson Support**: Jetson Thor with JetPack 7.0
- **Advanced Tracking**: New MaskTracker using Segment Anything Model 2 (SAM2)
- **Multi-View 3D Tracking (MV3DT)**: Enhanced object tracking with pose estimation
- **Inference Builder**: Streamlined YAML-to-deployment workflow
- **TAO 6 Models**: Native support for NVIDIA TAO 6 trained models
- **REST API**: New REST API support for nvdsanalytics and nvtracker plugins
- **Audio Enhancements**: Improved nvdsudpsrc/nvdsudpsink with configurable audio frame size and A/V resync

**Compatibility:**
- DeepStream 7.1 applications are fully compatible with DeepStream 8.0
- All existing DSL code continues to work without modification

### Important DeepStream 8.0 Changes

**Deprecated Features:**
- **OpenCV**: Deprecated by default in DeepStream 8.0 plugins (nvinfer, dsexample)
  - To use OpenCV with DS 8.0, rebuild DeepStream plugins with `WITH_OPENCV=1`
  - DSL's OpenCV integration (BUILD_WITH_OPENCV) continues to work

**Removed Features:**
- **Model Formats**: TensorFlow, UFF, and Caffe models are no longer supported
  - Use TensorRT engine files (.engine) or ONNX models instead
  - Existing TensorRT engines continue to work

- **Graph Composer**: DeepStream 8.0 is the last release supporting Graph Composer

### Platform Requirements

**Ubuntu 24.04 LTS** (New)
- Full support for Ubuntu 24.04 LTS
- All DSL features verified on Ubuntu 24.04

**Jetson Platforms**
- JetPack 7.0 required for DeepStream 8.0
- Support for Jetson Thor platform

**NVIDIA GPU Architectures**
- NVIDIA Blackwell architecture support
- All previous NVIDIA GPU architectures continue to be supported

## Migration Guide

### Migrating to DeepStream 8.0

**For OpenCV Users:**
If using DSL with `BUILD_WITH_OPENCV=true`:
1. DSL's OpenCV integration continues to work
2. If using DeepStream plugins that depend on OpenCV, rebuild them with `WITH_OPENCV=1`
3. See: [Installing OpenCV Dependencies](/docs/installing-dependencies.md#using-opencv)

**For Model Users:**
1. **TensorFlow/UFF/Caffe models**: Convert to TensorRT engine or ONNX format
   - Use `trtexec` to convert ONNX models to TensorRT engines
   - Use NVIDIA TAO Toolkit for training and exporting compatible models
2. **Existing TensorRT engines**: No changes needed, continue to work

**Version Checks in Code:**
- All existing version conditionals work correctly with DS 8.0
- `NVDS_VERSION_MAJOR` will be 8 for DeepStream 8.0
- No code changes required for version compatibility

## Building DSL with DeepStream 8.0

### Prerequisites
```bash
# Ubuntu 24.04 LTS (new)
sudo apt update && sudo apt-get install \
    libgstrtspserver-1.0-dev \
    gstreamer1.0-rtsp \
    libapr1 \
    libapr1-dev \
    libaprutil1 \
    libaprutil1-dev \
    libgeos-dev \
    libcurl4-openssl-dev
```

### Building DSL
```bash
# Build DSL (same as before)
make clean
make -j$(nproc)
sudo make install
```

### OpenCV Support with DeepStream 8.0
If you need OpenCV support with DeepStream 8.0:

```bash
# 1. Install OpenCV (if not already installed)
sudo apt-get install libopencv-dev

# 2. Rebuild DeepStream plugins with OpenCV support
cd /opt/nvidia/deepstream/deepstream/sources/gst-plugins/gst-nvinfer
sudo make clean
sudo make WITH_OPENCV=1 -j$(nproc)
sudo make install

cd /opt/nvidia/deepstream/deepstream/sources/gst-plugins/gst-dsexample
sudo make clean
sudo make WITH_OPENCV=1 -j$(nproc)
sudo make install

# 3. Build DSL with OpenCV
cd /path/to/deepstream-services-library
# Edit Makefile: Set BUILD_WITH_OPENCV:=true
make clean
make -j$(nproc)
sudo make install
```
